# ReactJS_UI_Learning
* building simple reactJS project - https://www.youtube.com/watch?v=UF0KcsJcRBY
* Open this project - and first ask copilot to install node in this machine


## A. PRE-REQUISITE
* Node
* Visual Studio Code with copilot

## B. COMMANDS IN REACTJS
* $$ node --verison
    * To check node version installed in your app

* $$ npm create vite@latest my-react-app 
    * To create ReactJS app
    * But this also asks which template you want or which typescript or javascript you want. learn about these also

* After that run this command to start the application
    cd my-react-app
    npm install
    npm run dev
